# Fitness Tracker App

Welcome to Fitness Tracker, a full-stack web application designed to help users log their workouts, set custom exercise goals, and maintain momentum through routine-based streaks and performance tracking.

This project was developed as a core requirement for CPS 493 Web Server Programming.

## 📝 Project Overview

The core mission of the platform is to provide a seamless, intuitive experience for anyone—regardless of their experience or fitness level—to quantify and track their exercise habits.

### ✨ Key Features
- **Workout Logging:** Track exercise details and history
- **Connections:** Follow other users and view their workouts
- **Admin Tools:** Manage and troubleshoot users, activities, and connections

### 🗺️ Planned Features
- **Goal Setting:** Define targets for time, distance, and frequency
- **Routine Builder:** Schedule weekly workouts
- **Consistency Streaks:** Reward consistent exercise habits
- **Personal Bests:** Highlight new PRs automatically
